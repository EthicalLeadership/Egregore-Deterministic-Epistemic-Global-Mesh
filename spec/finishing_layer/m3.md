# M3 Gate Contract — Terminal Non-Reentry

> **Scope:** Finishing Layer module linker.  
> **Binding status:** Constitutional. Removal or bypass requires an attested governance event.

## 1. What M3 is

M3 is not a comment, a TODO, or a placeholder. It is a build-phase validation check embedded in the Finishing Layer's module linker.

Every module introduced into the Egregore core must declare an `m3_decom_manifest` in its metadata. This manifest must include:

1. A list of all external systems that will depend on this module once activated.
2. A tested, repeatable procedure for safely draining those dependencies and restoring them to a pre-integration state.
3. A cryptographic signature from the Egregore Dependency Safety Board (BDSB) — a quorum of human domain experts and automated verifiers — attesting that the procedure is valid for the current system topology.

## 2. What the stub enforces

The M3 stub is the *only* path through the linker. At build time the linker runs:

```c
if (!module.manifest || !module.manifest.m3_verified) {
    fail_build("M3 VIOLATION: module lacks certified "
               "decommissioning plan. Integration blocked.");
    return LINK_ERROR;
}
```

If the certified decommissioning plan is absent, the build halts. The module cannot be deep-integrated silently.

## 3. Bootstrap exception

When the system is bootstrapped without the BDSB operational, the stub is replaced by a temporary policy:

- All modules are marked `m3_certification_pending`.
- The linker logs a permanent `EGREGORE_INITIAL_BOOTSTRAP` event on the transparency log.

This event is a standing public record that the system is in a pre-guardian state. Any subsequent removal of the M3 check after bootstrap will be recorded as a divergence from the baseline, and downstream clients that verify the transparency log will refuse the binary.

## 4. Why removal is detectable

The stub is a compile-time trapdoor that can only be deactivated by an attested governance event. Removing it without that event makes the build non-reproducible and cryptographically distinguishable from the legitimate Egregore lineage.
