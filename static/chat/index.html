Available commands

  • /help — show this help
  • /ask <prompt> — ask the active AI model
  • /model — show active model and available backends
  • /model <name> — switch model (deepseek-chat, claude-3-5-sonnet-20241022, etc.)
  • /agents — list discovered CLI agents
  • /agent <name> <instruction> — dispatch a CLI agent (admin/operator only)
  • /ingest <zarc> [last_n=100] — ingest .zarc tail into ANCHORUM
  • /compare <left.zarc> <right.zarc> [max_tail=50] — compare two archives
  • /integrity — run ANCHORUM integrity gate
  • /hold <case_id> <reason> — litigation hold (admin/operator)
  • /dossier <prompt> — generate deterministic dossier

Plain text is automatically routed to the active AI model (/ask). Anchorum commands require admin/operator role.
