# Local Source-Paper Archive

This folder contains open-access PDF copies of the primary sources paired with Griffiths – *Introduction to Quantum Mechanics*. They are kept locally so you can read and print them even when the canonical DOI links are paywalled or unreachable.

## Where the protocols live

Each file above has a corresponding reading protocol in `.library/protocols/` that tells you how to read it historically and epistemically safely.

## Mirrors used

- Born & Jordan: University of Tübingen — `born_jordan_ZPhys_34_858_1925.pdf`
- Davisson & Germer: Rochester Institute of Technology (Spiff) — `davisson.pdf`
- Gerlach & Stern: UC Berkeley Digital Collections — `cubanc_44_151_01207014a.pdf`
- Bell: Semantic Scholar cache
- Dirac Part I: Leiden University Lorentz Institute
- Dirac Part II: GitHub `Quantum-Papers` mirror

If any mirror becomes unavailable, the canonical DOI remains the authoritative citation.
